# Foto produk supermarket Indonesia

Foto pada folder ini berasal dari kontribusi pengguna Open Food Facts dan diunduh
melalui URL `image_front_url` pada API. Open Food Facts menyatakan foto produknya
tersedia dengan lisensi Creative Commons Attribution-ShareAlike.

- Sumber: https://world.openfoodfacts.org/
- Dokumentasi gambar: https://openfoodfacts.github.io/openfoodfacts-server/api/how-to-download-images/
- URL sumber tiap foto: `back/app/indonesia_catalog.py`
- Diakses: 27 Oktober 2026

Nama merek dan kemasan tetap merupakan hak pemilik merek masing-masing. Harga di
database MYMARKET adalah harga demo untuk kebutuhan aplikasi, bukan harga pasar langsung.
